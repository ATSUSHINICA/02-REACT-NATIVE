# Ejercicio 02 - Tarjeta de bienvenida

## Qué he aprendido
- En este Ejercicio he aprendido bastantes cosas pero lo que más podría destacar sería el utilizar View dentro de otro View crear subsecciones dentro de otras, para dar un aspecto visual más dinamico.

También aprendi nuevas propiedades que se pueden aplicar, por ejemplo el borderRadius que sirve para modificar cada esquina de bloque View de forma circular y que no acabe es punta, el padding y margin que sirve para dar de cierta forma espacios entre elementos, padding a aquellos elementos que estan dentro de su bloque, y margin aquellos que se encuentran al rededor de ellos. También sus complementos como top, buttom, left, right, para modificar cada lateral de forma independiente. También me enteré que existe una propiedad llamada gap que sirve para serparar elementos del mismo bloque a la misma distancia en vez de usar marginTop entre elementos.

## Respuesta a la pregunta de comprensión
¿Por qué usarías `padding` en una tarjeta en lugar de `margin` para separar el texto del borde?

El motivo es porque margin haría reaccionaria de forma que los elementos que esten al rededor-exterior de esa tarjeta tengan la distancia impuesta a su alrededo, mientras que padding afecta a los elementos que se encuentran dentro 
de esta tarjeta, permitiendo que exista una distancia entre el texto y el borde
